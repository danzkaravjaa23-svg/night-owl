Night Owl UB is a beta social and place-discovery app for adults aged 18 and over in Ulaanbaatar. Browse venues on a map, save favorites, and try profiles, photos, short videos, stories and messages. The main interface is in Mongolian.

This beta uses a separate staging service. Use test content and avoid private or sensitive information. Map activity reflects venue-tagged content, not live crowd levels or confirmed opening hours. Check venue details directly before visiting.

To create an account, use Sign in with Apple. Email sign-up confirmation is not yet available to beta testers, and Google sign-in is not enabled. Posts, stories, comments, notes, reviews and profile changes are published immediately. Text containing blocked words, web links or phone numbers is held for a moderator, and an item reported by several established testers is hidden until a moderator reviews it. This build may still show an older "sent for review" message after you post. Venue and event listings are still approved before they appear. Remote push delivery, calls, streaming, ticket sales and payments are not provided.

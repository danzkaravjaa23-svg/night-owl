[Яг дараалал ба батлах хүрээ](../../tools/deployment/STORE_BACKEND_ROLLOUT.md).

**2026-11-04 staging төлөв:** тусдаа Free [`night-owl-staging`](https://supabase.com/dashboard/project/sreojqqqhdzkfsrbvlpl) project (`sreojqqqhdzkfsrbvlpl`, Tokyo/Nano) дээр аппын schema/ACL baseline болон 008/009 **суусан**, бодит preflight/install/postflight бүгд PASS. Production хэрэглэгчийн өгөгдөл/файл хуулсангүй, шинэ төлбөртэй үйлчилгээ аваагүй. [Суулгалтын нотолгоо](evidence/staging-initialization.json).

Staging-ийн minimum Auth/медиа API acceptance **85 шалгалт PASS**: хоёр synthetic аккаунтын password login/refresh/profile trigger, PNG/MP4 upload/read, pending post/story, private/signed media болон бусдын/anonymous хандалтын хамгаалалт ажилласан. Cleanup-ийн дараа туршилтын аккаунт, profile, post, story, Storage object бүгд0. [API нотолгоо](evidence/staging-acceptance.json). Нийтийн email signup, moderator approve/reject/ban, Edge устгал/receipt recovery, recovery эрхийн бүрэн нийцэл, client/device acceptance болон production rollout хараахан дуусаагүй. Apple эрхээ авах нь эдгээр staging ажлыг дахин хийх шаардлага үүсгэхгүй; membership Active болсны дараа Apple provider/signing-ийн үлдсэн тохиргоог үргэлжлүүлнэ.

1. **Apple эрх.** Developer membership Active болсны дараа Team ID болон App Store Connect хандалтыг батална. Нууц үг, `.p8`/`.p12`, recovery code-ийг чат эсвэл GitHub-д оруулахгүй.
2. **Apple тохиргоо.** `com.nightowl.ub.nightOwlUb` App ID-ийн эзэмшил, Sign in with Apple capability, web Service ID/callback болон backend-ийн Apple keys тохируулна. [Дэлгэрэнгүй заавар](../APPLE_SIGN_IN_SETUP.md).
3. **Backend.** Local DB/медиа recovery, staging baseline + 008/009 болон minimum Auth/медиа API acceptance батлагдсан. Одоо тусдаа disposable аккаунтаар нийтийн email signup, moderator/ban, Edge-ийн устгал/receipt recovery, сонгосон report context, client болон retention ажиллагааг шалгаж дуусгана. Production Edge идэвхгүй хэвээр; өмнөх өгөгдөл/эрхийн нийцэл, recovery хариуцагчийг батлаад production SQL/client-ийг зохицуулан гаргана.
4. **Гарын үсэг ба төхөөрөмж.** Xcode Team/provisioning сонгон signed archive гаргаж, өөрийн iPhone/iPad дээр [16 acceptance case](REVIEW_TEST_PLAN.md)-ийг шалгана. Үүнд Apple нэвтрэлт/устгал, зураг/видео, permission, мессеж, pending review, тасалдсан устгал сэргээх багтана.
5. **Store материал.** Бодит build-ээс screenshot авна. Listing текст [metadata/en-US](metadata/en-US)-д бэлэн. Seller/contact, хариуцсан moderator, review account, media rights, нас, privacy болон encryption хариуг эзэмшигч батална.
6. **TestFlight → App Review.** Эхлээд internal TestFlight-д суулгаж шалгана. Бүх gate хаагдсаны дараа App Review-д илгээнэ. Эхний хувилбарт manual release саналтай; submission буюу нийтлэлт одоогоор хийгдээгүй.

Нийтлэгдсэний дараа код, дизайн, боломжоо шинэ version/build гаргаж өөрчилж болно. Metadata талбар бүрийн засах нөхцөл ялгаатай. Одоогийн шалгалтын үр дүн ба эх сурвалж: [App Store бэлтгэл](../APP_STORE_SUBMISSION.md).

# Night Owl — дизайн сонголт

2026-10-05. Хэрэглэгчийн сонгосон [approved reference](visuals/approved-reference.png) нь одоогийн дизайны үндсэн эх сурвалж. Reference нь дизайны самбар; ажилладаг аппын screenshot эсвэл бодит хэрэглэгчийн өгөгдөл биш. Одоогийн хувилбар нь үнэгүй апп: төлбөр, subscription, premium unlock, in-app purchase идэвхгүй. ## Approved reference ба өгөгдөл

Reference-ийн sample хүмүүс, username, followers/posts тоо, зураг, verification badge-ийг бүтээгдэхүүний өгөгдөл болгож хуулсангүй. Профайлд тухайн хэрэглэгчийн бодит cover/avatar/нэр/био/тоо харагдана. Avatar байхгүй үед өөрийн initial, cover байхгүй үед өмнөх хотын brand illustration хэрэглэнэ; owl нь хэрэглэгчийн хуурамч avatar болохгүй. “Хадгалсан” tab бодит `saved_posts`-ийг харуулдаг; “Tagged” гэж нэрлээд зохиомол контент нэмээгүй.

Reference доторх гудамж, газрын нэр, venue card-ийн зай/үнэлгээ нь жишээ. Бодит газрын зураг OSM tile ба өгөгдлийн сангийн байршил ашиглана; pin, үнэлгээ, байршлын баталгаажуулалт эсвэл badge зохиогоогүй. [Байршлын шалгалт](#байршлын-шалгалт) хэвээр хүчинтэй.

## Өдөр, шөнө ба хэмжээст UI

Шөнийн горим анхны сонголт хэвээр. Өдөр нь цайвар гадаргуу, бараан текст ашиглана; Систем нь төхөөрөмжийн brightness-ийг дагана. Profile, Settings, Feed, Messages болон map-ийн өнгө нийцэж өөрчлөгдөнө. Профайлын cover, зураг/видео дээрх цагаан үйлдлийн дүрс хадгалагдана. Хэмжээст glyph болон товч нь approved reference-ийн cover/feed/grid/footer байрлалыг сольсонгүй; owl mark нь сонгосон хавтгай дүрслэлээ хадгална.

Горимын хадгалалтыг дарааллаар гүйцэтгэнэ: эхлэх үед удаан ирсэн хуучин сонголт хэрэглэгчийн шинэ сонголтыг дарахгүй. Хадгалалт `false` эсвэл алдаа өгвөл зөвхөн хамгийн сүүлийн хүсэлтийн харагдацыг өмнөх хадгалсан горимд буцааж, storage/cache-ийг боломжтой үед сэргээнэ. Дэлгэцийн notifier dispose болсон хойно ирсэн үр дүн өнгийг өөрчлөхгүй. Энэ шинэчлэлийн GitHub push болон deployment баталгаажаагүй; [native, Apple болон серверийн release хязгаар](RELEASE_READINESS.md) хэвээр.

## Байршлын шалгалт

Нийтийн өгөгдлийг уншихад 712 бүртгэлээс 700 нь ` #тоо` төгсгөлтэй load-test мөр байсан. Серверийн өгөгдлийг устгаагүй. 12 газрыг жагсаалтад үлдээж, найман жишээ/анхдагч координатыг map pin болгохгүй. Эзэн өөр координат хадгалсан бол түүнийг дарж солихгүй.

- [Grand Khaan-ийн албан сайт](https://gk-irishpub.mn/) дахь Seoul Street хаяг, албан map-ийн орчныг [OSM node 13369164710](https://www.openstreetmap.org/node/13369164710)-той тулгасан: 47.9152094, 106.9138958.
- [Fat Cat-ийн албан хаяг](https://www.fatcatjazzclub.com/en/about/) болон [OSM node 6452841082](https://www.openstreetmap.org/node/6452841082): 47.9152012, 106.9174411.
- Эхлэх төв: [Сүхбаатарын талбай, OSM relation 15638347](https://www.openstreetmap.org/relation/15638347): 47.9188126, 106.9168967.
- Ikh Mongol Bar, Choijin Karaoke-ийн өгөгдлийн сан дахь координат хүчинтэй хүрээнд байна, тусдаа эх сурвалжаар баталгаажаагүй. Тэдгээрийг баталгаажаагүй гэж дэлгэц дээр тэмдэглэнэ.
- Үлдсэн найман газрын координатыг эзэд эсвэл оператор бодитоор бүртгэх шаардлагатай; тоо бүрэн харагдуулахын тулд цэг зохиогоогүй.

OSM нийтийн tile нь SLA-гүй. Өргөн хэрэглээний өмнө [tile policy](https://operations.osmfoundation.org/policies/tiles/)-г хангаж, лицензтэй provider сонгоно. Provider болон attribution-ийг build-ийн тохиргоогоор сольж болно.

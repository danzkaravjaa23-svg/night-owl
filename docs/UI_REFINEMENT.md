# Night Owl — UI сайжруулалт

2026-10-12. Үндсэн нил ягаан өнгө, доод цэсийн шилждэг гэрлийн эффектийг хадгалж, мэдээллийн дараалал болон уншихад хялбар байдлыг сайжруулав.

## Хийсэн өөрчлөлт

1. **Feed:** толгой хэсэг, story rail болон завсрыг багасгав. 390 × 844 хэмжээтэй дэлгэц дээр эхний нийтлэлийн зураг ойролцоогоор 50px эрт харагдана.
2. **Дүрс:** ердийн товчнуудын дүрсийг цэвэр, тод болгож, хэмжээст эффектийг онцлох үйлдэлд үлдээв.
3. **Доод цэс ба жижиг бичвэр:** үүсгэх товчийг `+` дүрстэй болгож, цэсийн нэр болон туслах бичвэрийг томруулж, ялгаралтыг нэмэгдүүлэв. Шилждэг нил ягаан spotlight хэвээр.
4. **Газрын зураг:** сонгосон газрын картыг өдөр/шөнийн горимд тохирсон авсаархан болгож, тайлбар ба холбоосыг «Дэлгэрэнгүй» хэсэгт байрлуулав. Чиглэл, хадгалах үйлдэл болон байршлын эх сурвалжийн сануулга шууд харагдана. Тэлэх/хураах нь газрын зургийн байрлалыг өөрчлөхгүй. Хөдөлгөөн багасгах тохиргоотой үед шууд шилжинэ.
5. **Профайл:** жинхэнэ нэрийг голчилж, @хаягийг доор нь байрлуулав. Cover болон завсрыг багасгаж, нийтлэлийн торыг дээшлүүлэв. Том бичвэр, урт нэр болон cover засах товчны хүрэлтийг хадгалав.
6. **Мессеж:** ачаалах алдааг давхар мэдэгдэлгүй, нэг дахин оролдох хэсгээр харуулна. Шинэчлэх үед алдаа гарвал өмнөх ярианууд харагдсаар байна. Хоосон төлөвөөс хүн хайх, үр дүнгүй хайлтыг цэвэрлэх үйлдэл нэмэв.

## Туршилтын орчин

[Шөнийн preview](http://localhost:5602/?theme=dark#/feed), [өдрийн preview](http://localhost:5602/?theme=light#/feed). Энэ холбоос локал preview сервер ажиллаж байх үед нээгдэнэ.

`tools/design_preview.dart` нь үндсэн дэлгэцүүдийг зохиомол жишээ өгөгдлөөр харуулна. Preview-ийн HTTP client production сервер рүү хүсэлт дамжуулахгүй. Зөвшөөрсөн унших үйлдлүүдийг жишээ өгөгдлөөр хариулж, өөрчлөх хүсэлтийг 405-аар татгалзана. `?messages=error` нь мессежийн ачаалах алдааг үзүүлэх зориулалттай.

## Баталгаажуулалт

- Flutter analysis: алдаагүй.
- Бүх 236 Flutter тест амжилттай. Мессежийн алдаа/дахин оролдох/шинэчлэх/хоосон төлөв, профайлын урт нэр ба том бичвэр, газрын картын тэлэх/хураах болон хөдөлгөөн багасгах хоёр тохиргооны шалгалт багтсан.
- Үндсэн production web build болон тусдаа debug preview build амжилттай.
- 390 × 844 хэмжээтэй браузерт feed, газрын зураг, профайл, мессежийг өдөр/шөнийн горимд үзэж шалгав. Газрын картыг тэлэх/хураах, өөр газар сонгох, хоосон мессежээс хүн хайх болон жишээ ачаалах алдааны төлөвийг шалгав.
- Эцсийн map засварын дараа шинэ браузерийн preview дээр өдөр/шөнийн тэлэх/хураах үйлдлийн error log хоосон.
- Өөр агентын нэмэлт унших хяналтаар navigation, бодит callback болон preview-ийн хүсэлт тусгаарлах хэсэгт саадтай асуудал илрээгүй.

Энэ өөрчлөлт локал код дээр хийгдсэн; commit, push болон нийтлэлт хийгдээгүй. Бодит утсан дээрх FPS болон store build хэмжигдээгүй.
